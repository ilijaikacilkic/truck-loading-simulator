# Utils

Shared helper logic is split here:

- `constants.js` - app constants, emails, logo path, product defaults, storage keys
- `trailerUtils.js` - trailer math, snapping, validation helpers
- `thumbnailUtils.js` - saved trailer SVG thumbnail generation
- `formatUtils.js` - display formatting helpers
- `shareUtils.js` - encode/decode trailer share links
- `excelUtils.js` - XLSX/CSV generation and email body formatting
- `fileUtils.js` - JSON backup, file reading, image reading, search helper
